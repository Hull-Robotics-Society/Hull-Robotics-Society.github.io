## OSRC Hardware Overview
The OSRC is built around powerful, **readily available hardware components**, including:

### **1. Raspberry Pi 5**
- The main computing unit, running Linux with ROS/ROS2.
- Handles processing, networking, and touchscreen UI.

### **2. Teensy 3.6**
- Handles low-latency input from joysticks and buttons.
- Communicates with the Raspberry Pi over USB.

### **3. Dual Joysticks & Buttons**
- Provides precise analog and digital inputs for robotic control.

### **4. 7" Touchscreen Display**
- Runs a UI interface for monitoring and controlling connected robots.

This setup ensures **high performance with real-time control capabilities**.
