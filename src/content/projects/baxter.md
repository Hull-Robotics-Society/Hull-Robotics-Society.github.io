Baxter is a two-armed collaborative robot with seven joints per arm and a screen for a face. Ours had been sitting unused, so the first job was getting it to boot, calibrate and accept commands again.

Since then we have documented the setup, written control code in Python and ROS, studied how the arm segments work, and choreographed a routine with Pepper.
